# K-dual 랩핑 사이트

이 프로젝트는 Timeless-UI를 활용하여 만들어진 랩핑 사이트입니다.

개인적 업무로 사용하던 사이트의 디자인과 불편한점을 개선한 랩핑 사이트입니다.

원본 사이트의 계정이 없다면 체험모드로만 랩핑 사이트를 둘러볼 수 있습니다.
